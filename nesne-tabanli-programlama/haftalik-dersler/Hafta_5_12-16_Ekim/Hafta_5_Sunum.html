Canlı: kitap s.52–53 Uygulama 10–11 (gün adı ve hafta içi/sonu). Boş case’ler (case 1: case 2: …) bir grup oluşturur ve aynı kodu paylaşır. Kitap s.52 · Kod
switch üç türde çalışır: sayı, karakter, metin
switch (sinif)                // sayı
{
    case 1: tur = "Birinci sınıf"; break;
    case 2: tur = "İkinci sınıf";  break;
    default: tur = "Bilinmiyor";   break;
}

switch (harf)                     // karakter
{
    case 'A': puan = 100; break;
    case 'B': puan = 85;  break;
    default:  puan = 0;   break;
}

switch (renk)                     // metin
{
    case "kırmızı": kod = "#FF0000"; break;
    case "mavi":    kod = "#0000FF"; break;
    default:        kod = "#000000"; break;
}
Kitap s.52
Switch içindeki değer ile case değerleri aynı türde olmalı. Case değerleri için değişken kullanılmaz. break, switch’ten çıkmayı sağlar.
Değiştir ve gözle
case "Mavi": yazıp renk = "mavi" ver. Hangi case çalışır?
default: metin eşleşmesi büyük/küçük harfe duyarlıdır. renk.ToLower() ile switch’e vermek çözümdür.
Switch ile yapılabilen her şey if/else if ile de yapılabilir (kitap s.53); switch tek değerin çok sayıda eşitliğini denetlerken daha okunur olur. Aralık denetimi (≥ 50) için else if daha uygundur (switch aralık bilmez; C# 9 desen eşleştirmesi bunu yapar, kitapta yok).

Kitap s.53–57: && yalnızca hepsi true ise true; || en az biri true ise true. Birden fazla koşul tek if içinde birleşir.
Canlı uygulama (kitap Tablo 2.2, Uygulama 12–15). Yaş aralığı için “yas >= 18 && yas <= 65” yazılır; “18 <= yas <= 65” yazımı C#’ta geçersizdir. private void btnSinif_Click(object sender, EventArgs e)
{

Özet
Bu hafta öğrendiklerimiz
İç içe if
İkinci soru yalnızca ilk koşul true ise sorulur; her seviyenin kendi else’i vardır.
switch
Tek değerin çok sayıda eşitliği; her dolu case break ile biter.
case grubu
Boş case’ler aynı kodu paylaşır; default eşleşme olmazsa çalışır.
&&
İki koşulun ikisi de true ise true. Yaş aralığı: yas >= 18 && yas <= 65.
||
İki koşuldan biri true ise true.
null
Seçim yokken SelectedItem null’dır; önce kontrol et.
Altı kavramı sırayla sorun. Sonraki hafta: ! operatörü, mantıksal operatör önceliği ve döngüler.

A)continueB)break (ya da return)C)endD)Hiçbir şey
Cevap: B) break olmadan sonraki case’e düşmek CS0163 hatasıdır.
3. Hiçbir case eşleşmezse hangisi çalışır?
A)defaultB)elseC)finallyD)break
Cevap: A) default eşleşme olmadığında çalışır.

A)DeğişkenB)Sabit değerC)Metot çağrısıD)TextBox

5. yas >= 18 && yas <= 65 ifadesi yas = 70 için ne verir?
