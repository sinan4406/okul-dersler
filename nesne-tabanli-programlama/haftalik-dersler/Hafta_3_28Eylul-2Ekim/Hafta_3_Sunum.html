İki sayı, bir tür

Dene

7 ve 2 ile üç türü karşılaştır. Sonra b = 0 yap. Sonra 2000000000 ve 2 ile int çarpımını dene.

Sonuç satırlarının yanındaki açıklamalar türe göre değişir.

Canlı uygulama (kitap s.36 Tablo 1.5’in genişletilmişi). int türünde 7 / 2 = 3 (ondalık atılır), 7 % 2 = 1. double’da 3,5 olur. b = 0 iken int ve decimal DivideByZeroException verir; double ise Infinity (sonsuz) ya da NaN (sayı değil) üretir. 2000000000 * 2 int’te taşar (unchecked): −294967296. Geçen haftaki taşma konusuna bağlayın.

Kitapta yok · piyasada böyle kullanılıyor

int / int: ondalığı sessizce atar

KİTAPTA YOK

7 / 2

int bölmesi: ondalık atılır → 3

7 / 2.0

Bir taraf double olunca sonuç double: 3,5

(double)7 / 2

Önce 7 double’a çevrilir: 3,5

-7 / 2

Sıfıra doğru kesilir: −3 (−4 değil)

-7 % 2

Kalanın işareti bölünenin işaretidir: −1

1 / 3 * 3

Soldan sağa: 1/3 = 0, sonra 0*3 → 0 (1 değil!)

Ortalama için: double ort = (double)toplam / adet; · Kitap Tablo 1.5’te yalnızca 8/2 örneğini verir.

Kitapta yok: int / int tam sayı bölmesidir. Öğrenciler ortalama, yüzde ve oran hesabında bu hatayı çok yapar. Çözümler: bir tarafı double/decimal yapmak ya da (double) dönüşümü. Negatif bölme sıfıra doğru keser (−7/2 = −3). Mod işleminde işaret bölünenden gelir (−7 % 2 = −1); bu, 4. haftada tek/çift sayı kontrolünde yanıltıcı olur: sayi % 2 == 1 negatif tek sayılarda yanlış sonuç verir.

Örnek 4 · Kod

Bölme ve mod birlikte

private void btnHesapla_Click(object sender, EventArgs e)
{
    int ogrenci  = Convert.ToInt32(txtOgrenci.Text);
    int mlKisi   = Convert.ToInt32(txtMl.Text);
    int koliAdet = Convert.ToInt32(txtKoli.Text);

    decimal litre = ogrenci * mlKisi / 1000m;   // ml → litre
    int tamKoli   = ogrenci / koliAdet;                   // dolu koli
    int artan     = ogrenci % koliAdet;                   // açık kolide kalan

    lblLitre.Text = "Toplam süt: " + litre + " litre";
    lblTam.Text   = "Tam koli: " + tamKoli;
    lblArtan.Text = "Açık kolide kalan: " + artan + " kutu";
}

Beklenen sonuç

Toplam süt 69 litre, tam koli 14, kalan 9 kutu.

Değiştir ve gözle

1000m yerine 1000 yaz. 345 öğrenci, 250 ml için litre kaç çıkar?

Doğrusu 86,25 litre. int bölmesiyle 86 çıkar (ondalık atılır). Süt miktarı eksik sipariş edilirdi.
Beklenen sonuç doğrulaması: 345*200 = 69000; 69000/1000m = 69. Değiştir-ve-gözle: 345*250 = 86250; 86250/1000 = 86 (int) ve 86,25 (decimal). Öğrencilerden “artan 9 kutu için kaç koli sipariş edilir?” sorusunu cevaplatın: 15; if ile bunu 4. haftada yazacağız.

Özet

Bu hafta öğrendiklerimiz

+ - * / %

Beş operatör; % kalanı verir.

int / int

Ondalığı atar. Ondalık için double ya da decimal.

Öncelik

Parantez, sonra * / %, sonra + - (soldan sağa).

Parantez

İfadenin anlamını değiştirir; belirsizlikte kullan.

Kapsam

Yerel değişken metotla biter; alan değişkeni formla yaşar.

KDV, net, koli

Gerçek hesaplar türe ve sıraya bağlıdır.

Altı kavramı sırayla sorun. Sonraki hafta: karar ifadeleri (if).
