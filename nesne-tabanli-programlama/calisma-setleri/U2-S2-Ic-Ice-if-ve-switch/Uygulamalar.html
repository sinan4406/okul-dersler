Beklenen davranış: öğün tanınırsa ve bakiye ücrete yetiyorsa lblSonuc “Ödeme alındı”, lblKalan “Kalan: … TL” yazar. Bakiye yetmiyorsa “Yetersiz bakiye”, öğün tanınmıyorsa “Öğün tanınmadı” yazılır (kalan yazılmaz). Örnekler: (35, Öğle, burslu değil) → Ödeme alındı, Kalan: 0 TL · (50, Akşam, burslu) → Ödeme alındı, Kalan: 35 TL · (10, Kahvaltı, burslu değil) → Yetersiz bakiye · (40, Pizza) → Öğün tanınmadı.

Hazır (hatalı) kod:

int bakiye = Convert.ToInt32(txtBakiye.Text);
int fiyat = 0;
switch ( txtOgun.Text )
{
    case "Kahvaltı":
        fiyat = 20;
        break;
    case "Öğle":
        fiyat = 30;
        break;
    case "Akşam":
        fiyat = 30;
        break;
    default:
        fiyat = 0;
        break;
}
if ( chkBurslu.Checked == true )
{
    fiyat = fiyat / 2;
}
if ( bakiye > fiyat )
{
    lblSonuc.Text = "Ödeme alındı";
    lblKalan.Text = "Kalan: " + (bakiye - fiyat) + " TL";
}
else
{
    lblSonuc.Text = "Yetersiz bakiye";
}

Görev: (1) Kodu forma yazıp yukarıdaki dört örnekle dene; yanlış çıkanları bul. (2) Mantık hatalarını (en az 3) düzelt. (3) Her hatanın yanına neden yanlış olduğunu bir cümleyle yorum olarak yaz. (4) En az 2 sınır durumu içeren kendi test tablonu (girdi → beklenen sonuç) yaz ve düzelttiğin kodla dene.

İpucu

Dört örneği tek tek dene ve hangisinin farklı çıktığına bak. Ücret tablosuyla kodu karşılaştır. Bakiye ücrete tam eşitken ne olması gerektiğini düşün. Öğün tanınmadığında fiyatın değeri ne oluyor, sonraki if buna nasıl davranıyor?
