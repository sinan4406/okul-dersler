KOLAY 2 uygulama · Sunumdaki örneğin benzerini kur ve çalıştır

1. Bilgi yarışması kaydı★★★★Form uygulaması

Okul kulübü, "Bilgi Avcıları" yarışmasına yalnız 10 ile 14 yaş arası (ikisi de dahil) öğrencileri kabul ediyor.

Bir yaş TextBox'ı (txtYas), bir buton (btnKaydet) ve bir etiket (lblSonuc) olan form yap. Yaş uygunsa etikete Kaydınız alındı, değilse Yaş sınırı dışında yazılsın.
  • 10 → Kaydınız alındı
  • 14 → Kaydınız alındı
  • 9 → Yaş sınırı dışında
  • 15 → Yaş sınırı dışında
İpucu

İki sınırı ayrı ayrı yaz; aralıkta iki koşul birlikte sağlanmalı. Sınır değerlerini (10 ve 14) mutlaka dene.

2. Otomatik karanlık mod★★★★Form uygulaması

Bir telefon uygulaması, saat 19:00 ve sonrasında ya da sabah 07:00'den önce karanlık temaya geçiyor.

Saat için bir TextBox (txtSaat, 0-23 arası tam sayı), btnKontrol ve lblTema olan form yap. Karanlık tema zamanıysa Karanlık tema, değilse Aydınlık tema yazılsın.
  • 6 → Karanlık tema
  • 7 → Aydınlık tema
  • 18 → Aydınlık tema
  • 19 → Karanlık tema
  • 23 → Karanlık tema
İpucu

Gece saatleri iki ayrı parçadır ve biri doğruysa tema karanlıktır. İki yanı da tam karşılaştırma olmalı.

ORTA 2 uygulama · Öğrendiğini yeni bir duruma uygula

3. Nabız bandı uyarısı★★★★Form uygulaması

Akıllı bileklik, dinlenme nabzı 60 ile 100 arasındaysa her şey yolunda kabul eder; dışındaysa uyarır. Sensör 30'un altında ya da 220'nin üstünde değer okursa ölçüm hatalıdır.

txtNabiz, btnKontrol, lblDurum olan formu yap. Sonuç üç durumdan biri olsun: Geçersiz ölçüm, Uyarı: nabız normal dışı, Nabız normal. "Normal dışı" koşulunu yazarken en az bir yerde !( … ) kullan.
  • 25 → Geçersiz ölçüm
  • 45 → Uyarı: nabız normal dışı
  • 60 → Nabız normal
  • 100 → Nabız normal
  • 130 → Uyarı: nabız normal dışı
  • 230 → Geçersiz ölçüm
İpucu

Önce hatalı ölçümü ayıkla (else if zincirinin başında). Sonra "normal" aralığı yazıp başına ! koy. Hatalı ölçümü ayıklamazsan 25 de "uyarı" olur.

4. Apartman kapı kilidi★★★★Form uygulaması

Apartman girişi iki yoldan açılır: geçerli anahtar kartı (chkKart işaretli) ya da doğru şifre (1234) ile birlikte saatin 06:00-23:00 arasında olması (gece şifre kabul edilmez).

txtSifre, txtSaat, chkKart, btnAc ve lblKapi olan formu yap. Kapı açılırsa Kapı açıldı, açılmazsa Giriş reddedildi yazılsın.
  • Kart ✓ · şifre 0000 · saat 2 → Kapı açıldı
  • Kart ✗ · şifre 1234 · saat 14 → Kapı açıldı
  • Kart ✗ · şifre 1234 · saat 3 → Giriş reddedildi
  • Kart ✗ · şifre 9999 · saat 14 → Giriş reddedildi
İpucu

İki yol = araları ||. İkinci yolun içinde üç şart var ve hepsi gerekli. Hangi bölümü paranteze alırsan öncelik sorunu çıkmaz? Şifreyi sayıya çevirmen gerekmez; metin karşılaştırması yeter.

Hazır (hatalı) kod:

if ( txtYas.Text == "" || txtBoy.Text == "" )
{
    lblKarar.Text = "Yaş ve boyu yazın";
    lblKategori.Text = "";
}
else
{
    int yas = Convert.ToInt32(txtYas.Text);
    int boy = Convert.ToInt32(txtBoy.Text);
    lblKategori.Text = "";

    if ( boy < 120 || boy > 230 )
    {
        lblKarar.Text = "Geçersiz boy";
    }
    else if ( yas < 14 && yas > 18 )
    {
        lblKarar.Text = "Yaş uygun değil";
    }
    else if ( chkRapor.Checked == false )
    {
        lblKarar.Text = "Sağlık raporu gerekli";
    }
    else if ( chkKart.Checked == false || chkBelge.Checked == false )
    {
        lblKarar.Text = "Kimlik belgesi gerekli";
    }
    else
    {
        lblKarar.Text = "Kayıt kabul";
        if ( boy >= 190 || yas >= 16 )
        {
            lblKategori.Text = "Kategori: Büyükler";
        }
        else
        {
            lblKategori.Text = "Kategori: Gençler";
        }
    }
}

Görev: (1) Kodu forma yazıp tablodaki yedi örnekle dene; yanlış çıkanları bul. (2) Üç mantık hatasını düzelt. (3) Her hatanın yanına neden yanlış olduğunu bir cümleyle yorum olarak yaz. (4) En az 2 sınır durumu içeren (ör. 14 ve 18 yaş, 190 cm) kendi test tablonu yaz ve düzelttiğin kodla dene.

İpucu

Yedi örneği tek tek dene; hangi satırlar tablodan farklı çıkıyor? 13 yaşındaki başvuru neden geçiyor: hangi sayı hem 14'ten küçük hem 18'den büyük olabilir? "Ya da" ile "ve" kelimelerinin kodda hangi operatöre karşılık geldiğini kural cümleleriyle karşılaştır.
