Stajyerin kodu (butonun Click olayında):

int saat = Convert.ToInt32(txtSaat.Text);
int ucret = 0;
if ( chkAbone.Checked == true )
{
    ucret = 0;
}
if ( saat < 1 )
{
    ucret = 0;
}
else if ( saat <= 8 )
{
    ucret = 40;
}
else if ( saat <= 3 )
{
    ucret = 20;
}
else
{
    ucret = 100;
}
string durum;
if ( ucret == 0 )
{
    durum = "Ücretsiz çıkış";
}
else
{
    durum = "Ödenecek: " + ucret + " TL";
}
lblUcret.Text = durum;
lblSaat.Text = "Kalış: " + saat + " saat";

Görev: (1) Kodda en az 3 mantık hatası bul; her birini düzeltip bir cümleyle neden yanlış olduğunu yorum satırına yaz. (2) Düzelttiğin program için kendi test tablonu hazırla: en az 5 satır (süre, abonelik, beklenen sonuç); içinde en az 2 sınır durumu olsun. (3) Programı bu tabloyla çalıştır.

İpucu

Kod derleniyor, hata vermiyor: sorun mantıkta. Sınır saatleri (1, 3, 8) ve abonelik kartlı bir girdiyle çalıştırıp sonucu tarifeyle karşılaştır; hangi satır yanlış sonuç verdiriyor, oradan geriye doğru git.

btnAl:

  • Tutar seçilen ürün ve kutulara göre bulunur.
  • Para kutusu boşsa Önce para at yazılır; hiçbir kayıt değişmez.
  • Para yeterliyse Afiyet olsun! Para üstü: … TL yazılır, ListBox’a Tost - 27 TL gibi bir satır eklenir ve satış kaydı güncellenir.
  • Para yetmiyorsa Yetersiz: … TL eksik yazılır; ListBox ve kayıtlar değişmez.

btnGunSonu: o ana kadarki satış adedi, toplam kazanç ve satış başına ortalama kazanç lblRapor’da gösterilir. Hiç satış yoksa Bugün henüz satış yok yazılır. Toplam kazanç 200 TL ve üstündeyse rapora Hedef tamam eklenir.

Örnek: Tost + büyük boy + öğrenci, para 50 → Para üstü: 23 TL; ardından Su, para 10 → Para üstü: 0 TL; rapor: Satış: 2 adet, Kazanç: 37 TL, Ortalama: 18 TL.

Bir özellik daha ekle: kendi tasarladığın ek bir özellik (ör. bir ürün için stok sınırı, yeni bir ürün, “son satışı sil”). Ne yaptığını yorum satırında bir cümleyle açıkla. Ayrıca en az 2 sınır durumu içeren kendi test tablonu hazırla (ör. tam para, 0 satışlı rapor).

İpucu

İki olay, iki ayrı iş: btnAl tek satışı işler, btnGunSonu birikmiş toplamı gösterir. Birikmesi gereken değerler butonun içinde değil, formun düzeyinde durmalı. Para kutusu boşken sayıya çevirme; satışın gerçekleşip gerçekleşmediğini bir bool ile tut.
