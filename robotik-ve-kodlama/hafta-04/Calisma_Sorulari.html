1. IDE kurulum sırası★☆☆

Arduino IDE’yi indirip kuruyorsun.

Yapılacaklar

Adımları 1’den 6’ya sırala:

  1. ( ) Kurulum sihirbazında “Install USB driver” seçeneğini işaretli bırak.
  2. ( ) Resmi sitede Software → Downloads menüsüne gir.
  3. ( ) İşletim sistemini seç, JUST DOWNLOAD ile indir.
  4. ( ) Kurulumu bitir ve IDE’yi aç.
  5. ( ) İndirilen kurulum dosyasını çalıştır.
  6. ( ) Kartı USB ile bilgisayara bağla.

4. Hız seçici★★☆

Yerleşik LED düğmeye göre hız değiştiriyor.

Yapılacaklar

Düğme D2’de (pull-down). Basılı değilken yerleşik LED 500 ms yanıp 500 ms sönsün; basılıyken 100 ms yanıp 100 ms sönsün. Programı yaz.

  1. Düğmeye bastıktan sonra tepkinin gecikmesinin nedeni nedir?

İpucu: LED_BUILTIN, Uno’da D13’tür.

5. Kalp atışı ve arıza★★★

Hasta monitöründe yeşil kalp atışı, arızada kırmızı uyarı.

Yapılacaklar

Yeşil LED D6’da, kırmızı LED D7’de, düğme D2’de (arıza simgesi, pull-down). Normalde yeşil 100 ms yanıp 900 ms sönsün. Düğmeye basılınca yeşil söner, kırmızı 150 ms aralıkla çakar. Programı yaz.
