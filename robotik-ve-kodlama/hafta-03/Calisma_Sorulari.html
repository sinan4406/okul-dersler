2. Ultrasonik mesafe hesabı★★☆

Ses dalgası cisme gidip geri döner; mesafe, gidiş-dönüş süresinin yarısına göre bulunur. Ses hızı 343 m/s = 0,0343 cm/µs.

Yapılacaklar

  1. Sensör 1166 µs sonra yankı aldı. Cisim kaç cm uzakta?
  2. Yankı süresi 580 µs ise mesafe yaklaşık kaç cm’dir?
  3. 2 m uzaktaki bir cisim için gidiş-dönüş süresi yaklaşık kaç ms’dir?

İpucu: Mesafe = süre × 0,0343 / 2 (cm).

4. Kodu oku: basılıyken yan★★☆

Düğme D2’de, LED D13’te.

Yapılacaklar

void setup() {
  pinMode(2, INPUT);
  pinMode(13, OUTPUT);
}

void loop() {
  if (digitalRead(2) == HIGH) {
    digitalWrite(13, HIGH);
  } else {
    digitalWrite(13, LOW);
  }
}
  1. Düğmeye basılıyken LED ne yapar? Bırakınca?
  2. İki yerdeki HIGH ve LOW yer değiştirirse ne olur?
