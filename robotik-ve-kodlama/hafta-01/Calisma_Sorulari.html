1. Pin avı★☆☆

Arduino Uno’nun üzerindeki pinleri tanıyorsun.

Yapılacaklar

  1. Hangi iki pin seri haberleşmeye (RX/TX) ayrılmıştır?
  2. PWM çıkışı verebilen dijital pinleri yaz.
  3. Analog giriş pinleri hangileridir?
  4. Kart üzerindeki yerleşik (L) LED hangi pine bağlıdır?
  5. Bir LED’i kartın dijital pinine bağlamak için hangi aralık tercih edilir?

İpucu: Kartın üzerindeki yazılara bak; PWM pinlerinin yanında ~ işareti var.

3. Kapı zilinde sinyalin yolu★★☆

Düğmeye basınca zilin çalmasını sağlayan zinciri sıralıyorsun.

Yapılacaklar

Aşağıdaki adımları 1’den 5’e doğru sırala:

  1. ( ) Çıkış portu hoparlöre sinyal gönderir.
  2. ( ) Kullanıcı düğmeye basar.
  3. ( ) Giriş portu düğmenin sinyalini alır.
  4. ( ) Hoparlör zil sesi çalar.
  5. ( ) MİB, flash bellekteki programı çalıştırıp karar verir.

4. ADC hesabı★★☆

Uno’nun analog girişi 5 V’u 0–1023 arası sayıya çevirir (1023 = 5 V).

Yapılacaklar

analogRead değeriGerilim (V)
0
256
512
1023
  1. Pindeki gerilim 3,3 V ise analogRead yaklaşık kaç değer verir?
  2. Neden sonuç tam sayı olmayabilir; analogRead’in sonucu hangi türdedir?

İpucu: Gerilim = değer × 5 / 1023.
