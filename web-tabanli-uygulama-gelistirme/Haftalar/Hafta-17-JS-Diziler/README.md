# Hafta 17 - Diziler

**Öğrenme Birimi:** Etkileşim (Javascript)
**Ders Saati:** 8 (Haftalık)
**Durum:** Hazır (tam içerik)

## Bu Hafta İşlenecek Konular
- Dizilerin kullanımı

## Kazanımlar
- Dizileri kullanarak etkileşimli sayfa geliştirir.

## Güncel Konu Notu (Öğretmen İçin)
Modern dizi metotları (map, filter, reduce, find, includes, at()) ile klasik for döngüsüne alternatif fonksiyonel yaklaşımlar.
