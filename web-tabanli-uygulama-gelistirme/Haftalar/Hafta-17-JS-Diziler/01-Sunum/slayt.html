Javascript — Bölüm 4

Diziler
(Arrays)

Birden fazla veriyi tek bir değişkende, sıralı biçimde saklamayı ve işlemeyi öğreniyoruz.

01 — Neden Diziye İhtiyacımız Var?

Tek Tek Değişken mi, Dizi mi?

DİZİ OLMADAN

5 Öğrenci = 5 Değişken

let ogrenci1 = "Ayşe";
let ogrenci2 = "Mehmet";
let ogrenci3 = "Elif";
// 50 öğrenci olsa?! 😱
DİZİ İLE

Tek Değişken, Tüm Liste

let ogrenciler = [
  "Ayşe", "Mehmet", "Elif"
];
Dizi (array), sıralı bir kutu dizisi gibi düşünülebilir — her kutunun bir numarası (index) ve içinde bir değer vardır.
02 — Tanım

Dizi Oluşturma

  • Köşeli parantez [ ] ile oluşturulur, elemanlar virgülle ayrılır.
  • Bir dizi farklı veri tiplerini bir arada tutabilir (metin, sayı, boolean...).
  • Diziler de let veya const ile tanımlanır — const ile tanımlanan bir dizinin içeriği yine de değiştirilebilir (sadece diziyi başka bir diziyle değiştiremezsiniz).
Kod
const notlar = [85, 90, 72, 100];
const karisik = ["Ali", 16, true];
03 — En Kritik Kural

Index, 0'dan Başlar!

  • Bir dizinin ilk elemanının index'i 0'dır, 1 değil!
  • Bu, programlamaya yeni başlayanların en sık düştüğü tuzaktır — gerçek hayatta 1'den saymaya alışkınız, dizilerde 0'dan sayarız.
"Ayşe"index 0
"Mehmet"index 1
"Elif"index 2
"Can"index 3

4 elemanlı bir dizide son index 3'tür — 4 değil! (Uzunluk 4, ama son index = uzunluk − 1)

04 — Erişim

Dizi Elemanına Ulaşmak

  • Bir elemana ulaşmak için köşeli parantez içine index yazılır: dizi[index]
  • Var olmayan bir index'e erişmeye çalışırsanız hata almazsınız — undefined değeri alırsınız. Bu, hatayı fark etmeyi zorlaştırır!
Kod
const ogrenciler = ["Ayşe", "Mehmet", "Elif"];

console.log(ogrenciler[0]); // "Ayşe"
console.log(ogrenciler[2]); // "Elif"
console.log(ogrenciler[5]); // undefined (hata vermez!)
05 — Yararlı Özellik

dizi.length

  • Bir dizide kaç eleman olduğunu verir.
  • Son elemana ulaşmanın güvenli yolu: dizi[dizi.length - 1]
  • Dikkat: dizi[dizi.length] son elemanı VERMEZ — bir fazlasını (yani olmayan bir kutuyu) sormuş olursunuz.
Kod
const notlar = [85, 90, 72, 100];
console.log(notlar.length);          // 4
console.log(notlar[notlar.length - 1]); // 100 (doğru: son eleman)
06 — Canlı Kanıt — "Kayıp Eleman" Hatası

Off-by-One (Bir Fazla/Bir Eksik) Hatası

HATALI

<= kullanmak

for (let i = 0; i <= notlar.length; i++) {
  console.log(notlar[i]);
}
// son satırda: undefined 😬
DOĞRU

< kullanmak

for (let i = 0; i < notlar.length; i++) {
  console.log(notlar[i]);
}
// tam 4 satır, hepsi gerçek not
Bu hatayı birazdan örnek uygulamada gerçek konsol çıktısında göreceğiz — kayip-eleman.html dosyasında aynı hatayı kendi gözlerinizle bulup düzelteceksiniz.
07 — Değiştirme

Dizi Elemanını Güncellemek

  • Bir elemanı değiştirmek için o index'e yeni bir değer atarız.
  • Diziyi yeniden oluşturmaya gerek yoktur — sadece ilgili kutunun içeriği değişir.
Kod
const notlar = [85, 90, 72, 100];
notlar[2] = 95; // index 2'deki 72, 95 oldu
console.log(notlar); // [85, 90, 95, 100]
08 — Ekleme / Çıkarma

push() ve pop()

push() — Sona Ekler

notlar.push(88);
// diziye sona 88 eklendi

pop() — Sondan Siler

notlar.pop();
// dizinin son elemanı silindi
Benzer şekilde unshift() başa ekler, shift() baştan siler — daha az kullanılır ama bilmekte fayda var.
09 — Gezinme — Klasik Yöntem

for Döngüsüyle Dizi Gezme

  • En eski ve en kontrol edilebilir yöntemdir — index'e ihtiyacınız varsa hâlâ tercih edilir.
  • Koşulu i < dizi.length yazmayı unutmayın (bkz. slayt 6).
Kod
const ogrenciler = ["Ayşe", "Mehmet", "Elif"];

for (let i = 0; i < ogrenciler.length; i++) {
  console.log(i + ". öğrenci: " + ogrenciler[i]);
}
10 — Kod Karşılaştırma — Klasik vs Modern

for vs forEach()

KLASİK

for döngüsü

for (let i = 0; i < ogrenciler.length; i++) {
  console.log(ogrenciler[i]);
}
MODERN

forEach()

ogrenciler.forEach(function(isim) {
  console.log(isim);
});
forEach, index hesaplama derdini ortadan kaldırır — off-by-one hatası yapma ihtimali sıfırlanır. Bu yüzden günümüzde çoğu geliştirici, index'e ihtiyaç yoksa forEach'i tercih eder.
11 — Yeni Dizi Üretmek

map() ile Dönüştürme

  • map(), mevcut diziyi değiştirmez — her elemanı dönüştürüp yeni bir dizi döndürür.
  • Örneğin bir isim listesinden HTML <li> satırları üretmek için idealdir.
Kod
const buyukHarfli = ogrenciler.map(function(isim) {
  return isim.toUpperCase();
});
console.log(buyukHarfli); // ["AYŞE","MEHMET","ELİF"]
console.log(ogrenciler);  // orijinal dizi DEĞİŞMEDİ
12 — Hızlı Tur

Diğer Faydalı Dizi Metotları

filter()
Koşulu sağlayan elemanları yeni bir dizide toplar (örn. 70 üstü notlar)
find()
Koşulu sağlayan İLK elemanı bulur, bulamazsa undefined döner
includes()
Bir değerin dizide olup olmadığını true/false olarak söyler
at(-1)
Negatif index ile sondan sayarak eleman getirir — modern bir kısayol
Bu metotları şimdilik tanıyor olmanız yeterli — kullanım örneklerini önümüzdeki uygulamalarda pekiştireceğiz.
13 — Gerçek Proje

"Okulum" — Bölümler Listesi Artık Diziden Geliyor

ÖNCEDEN — HTML'e elle yazılmış
<ul>
  <li>Bilişim Teknolojileri</li>
  <li>Elektrik-Elektronik</li>
  <li>Makine Teknolojisi</li>
</ul>
ŞİMDİ — JS dizisinden üretiliyor
const bolumler = ["Bilişim Teknolojileri",
  "Elektrik-Elektronik", "Makine Teknolojisi"];

bolumler.forEach(function(bolum) {
  liste.innerHTML += `<li>${bolum}</li>`;
});
Artık yeni bir bölüm eklemek için HTML'i değil, sadece diziyi güncellemek yeterli — bu, "veriyi kodun içine gömmemek" prensibinin ilk somut örneği.
