# Hafta 07 - Bağlantı (Köprü) Elemanları

**Öğrenme Birimi:** HTML5
**Ders Saati:** 8 (Haftalık)
**Durum:** Hazır (tam içerik)

## Bu Hafta İşlenecek Konular
- Bağlantı (köprü) özellikleri
- Site içi ve site dışı bağlantılar
- Bağlantı elemanlarının kullanım şekilleri

## Kazanımlar
- Web sayfaları arasında bağlantı sağlayan HTML kodunu uygular.

## Güncel Konu Notu (Öğretmen İçin)
target="_blank" ile rel="noopener noreferrer" güvenlik gerekliliği, çapa (anchor) bağlantılarla sayfa içi gezinme, site haritası (sitemap.xml) ve SEO ilişkisi.
