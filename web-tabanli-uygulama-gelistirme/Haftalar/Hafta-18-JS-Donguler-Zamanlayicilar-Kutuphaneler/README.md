# Hafta 18 - Döngüler, Zamanlayıcılar ve Popüler Javascript Kütüphaneleri

**Öğrenme Birimi:** Etkileşim (Javascript)
**Ders Saati:** 8 (Haftalık)
**Durum:** Hazır (tam içerik)

## Bu Hafta İşlenecek Konular
- Döngülerin kullanımı ve özellikleri
- Zamanlayıcıların (setTimeout/setInterval) kullanımı
- Popüler Javascript kütüphaneleri (jQuery, React, Angular, Vue, vd.)

## Kazanımlar
- Döngüleri kullanarak etkileşimli sayfa geliştirir.
- Popüler javascript kütüphanelerini listeler.

## Güncel Konu Notu (Öğretmen İçin)
jQuery'nin günümüzde büyük ölçüde yerini modern (vanilla) JS'in ve fetch API'nin alması; React/Vue gibi bileşen tabanlı kütüphanelerin/framework'lerin günümüz front-end ekosistemindeki yaygın rolü (tanıtım amaçlı farkındalık).
