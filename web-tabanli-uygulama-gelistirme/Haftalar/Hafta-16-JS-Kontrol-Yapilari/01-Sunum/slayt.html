Javascript — Bölüm 3

Kontrol Yapıları

Kodumuza karar verme yeteneği kazandırıyoruz — "eğer şu doğruysa, şunu yap".

01 — Neden Gerekli?

Bilgisayar Nasıl Karar Verir?

  • Şimdiye kadar yazdığımız kod hep yukarıdan aşağı, sırayla çalıştı.
  • Gerçek uygulamalarda karar vermemiz gerekir: "Form boşsa hata göster", "Yaş 18'den büyükse izin ver".
  • Kontrol yapıları (if/else, switch), koşula göre kodun farklı yollara sapmasını sağlar.
02 — Temel Söz Dizimi

if / else if / else

  • Parantez içindeki koşul true ise { } içindeki kod çalışır.
  • else if ile birden fazla koşul sırayla kontrol edilebilir.
  • else, hiçbir koşul sağlanmazsa çalışacak "son çare" bloğudur.
Kod
if (not >= 85) {
  console.log("Pekiyi");
} else if (not >= 70) {
  console.log("İyi");
} else {
  console.log("Geliştirilmeli");
}
03 — Sorular Sorma

Karşılaştırma Operatörleri

  • > < >= <= — büyük/küçük/eşit karşılaştırmaları
  • === — tam eşit mi? (değer VE tip aynı olmalı)
  • !== — tam eşit değil mi?
  • Her karşılaştırma bir boolean (true/false) sonucu üretir — bu sonuç if'in içine konur.
Kod
console.log(10 > 5);    // true
console.log(10 === "10"); // false — tip farklı!
04 — Kod Karşılaştırma

== mi, === mi?

== — TİP ZORLAR

Şaşırtıcı sonuçlar verebilir

console.log(5 == "5");      // true
console.log(0 == false);    // true
console.log("" == false);   // true
=== — TİP DE KONTROL EDER

Güvenli ve tahmin edilebilir

console.log(5 === "5");     // false
console.log(0 === false);   // false
console.log("" === false);  // false
Kural: Bu dersten itibaren her zaman === ve !== kullanacağız. Birazdan örnek uygulamada bu şaşırtıcı sonuçları canlı konsolda göreceğiz.
05 — Koşulları Birleştirme

Mantıksal Operatörler

  • && (VE) — iki koşul da doğruysa true
  • || (VEYA) — en az biri doğruysa true
  • ! (DEĞİL) — bir koşulun tersini alır
Kod
if (yas >= 18 && ehliyetVar) {
  console.log("Araç kullanabilir");
}

if (!eposta.includes("@")) {
  console.log("Geçersiz e-posta");
}
06 — Modern Kısayollar

Mantıksal Kısayol Operatörleri

  • ?? (nullish coalescing) — sol taraf null/undefined ise sağ taraftaki varsayılan değeri kullanır.
  • && kısa devre — sol taraf false ise sağ taraf hiç çalıştırılmaz, kısa bir "varsa yap" ifadesi için kullanılabilir.
Kod
const kullaniciAdi = girilenAd ?? "Misafir";
// girilenAd boşsa "Misafir" kullanılır
07 — Alternatif Yapı

switch İfadesi

  • Tek bir değeri, birden fazla sabit değerle karşılaştırırken kullanılır (örn. gün numarası, seçim menüsü).
  • Her case sonunda break unutulmamalı — aksi hâlde kod bir sonraki case'e "düşer" (fall-through).
Kod
switch (gun) {
  case 1: console.log("Pazartesi"); break;
  case 2: console.log("Salı"); break;
  default: console.log("Bilinmiyor");
}
08 — Kod Karşılaştırma

if/else Yığını mı, switch mi?

if/else ZİNCİRİ

Çok tekrar eden koşul varsa uzar

if (gun === 1) { ... }
else if (gun === 2) { ... }
else if (gun === 3) { ... }
// ... 7 gün boyunca devam eder
switch

Aynı değişkenin çoklu eşitlik kontrolünde daha okunaklı

switch (gun) {
  case 1: ...; break;
  case 2: ...; break;
  // ...
}
Aralık kontrolü (örn. not >= 85) gerekiyorsa switch uygun değildir — o durumda if/else if kullanmaya devam ederiz.
09 — Kısa ve Öz

Üçlü (Ternary) Operatör

if/else — 4 satır

Basit bir karar için uzun

let durum;
if (yas >= 18) {
  durum = "Yetişkin";
} else {
  durum = "Çocuk";
}
Ternary — 1 satır

koşul ? doğruysa : yanlışsa

const durum = yas >= 18 ? "Yetişkin" : "Çocuk";
Ternary, sadece basit ve tek satırlık kararlar için tercih edilir — karmaşık mantıkta okunabilirlik için `if/else` daha uygundur.
10 — Gerçek Proje

"Okulum" Formuna Doğrulama Ekleme

  • Form gönderilmeden önce üç kontrol yapıyoruz: ad boş mu, e-posta "@" içeriyor mu, mesaj boş mu.
  • Her hatalı durumda return; ile fonksiyonu orada durduruyoruz.
if (ad === "") {
  geriBildirimGoster(kutu, "hata", "Lütfen adınızı yazın.");
  return;
}

if (!eposta.includes("@")) {
  geriBildirimGoster(kutu, "hata", "Geçerli bir e-posta girin.");
  return;
}
