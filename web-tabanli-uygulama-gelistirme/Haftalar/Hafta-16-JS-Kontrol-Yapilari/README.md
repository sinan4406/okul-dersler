# Hafta 16 - Kontrol Yapıları

**Öğrenme Birimi:** Etkileşim (Javascript)
**Ders Saati:** 8 (Haftalık)
**Durum:** Hazır (tam içerik)

## Bu Hafta İşlenecek Konular
- Koşullu ifadelerin kullanımı (if/else, switch)

## Kazanımlar
- Kontrol yapılarını kullanarak etkileşimli sayfa geliştirir.

## Güncel Konu Notu (Öğretmen İçin)
Üçlü (ternary) operatör ve mantıksal kısayol (?? , &&) kullanımıyla daha okunabilir koşullu kod yazımı.
