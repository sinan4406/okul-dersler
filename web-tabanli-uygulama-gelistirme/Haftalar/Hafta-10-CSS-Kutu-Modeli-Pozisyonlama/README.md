# Hafta 10 - Kutu Modeli (Box Model) ve Pozisyonlama

**Öğrenme Birimi:** CSS (Basamaklı Stil Şablonu)
**Ders Saati:** 8 (Haftalık)
**Durum:** Hazır (tam içerik)

## Bu Hafta İşlenecek Konular

- Görünüm ve pozisyon ayarları (display, position)

## Kazanımlar
- Kutu modeli özelliklerini açıklar.
- Görünüm ve pozisyon ayarlarının nasıl yapıldığını açıklar.
