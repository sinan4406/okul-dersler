01 — Üçüncü Dil

Javascript Nedir?

  • Javascript (JS), tarayıcıda çalışan, gerçek bir programlama dilidir — HTML/CSS'ten farklı olarak hesaplama yapar, karar alır, verileri hatırlar.
  • Üçlü benzetme: HTML = iskelet (yapı), CSS = kıyafet (görünüm), JS = kaslar/sinir sistemi (hareket, tepki, davranış).
  • Bir butona tıklayınca bir şeyin değişmesi, bir formun kontrol edilmesi, bir sayacın çalışması — hepsi JS'in işi.
  • JS, Java ile aynı dil değildir — sadece isimleri benzer, 1995'te pazarlama amacıyla benzer isim verilmiştir.
02 — Kod Nereye Yazılır? — Kod Karşılaştırma

Üç Yöntem, Tek Doğru Tercih

SATIR İÇİ — kaçının

HTML İçine Gömülü

<button onclick="alert('Merhaba')">
  Tıkla
</button>
HARİCİ DOSYA — tercih edilen

Ayrı bir .js Dosyası

// script.js
const btn = document.querySelector("button");
btn.addEventListener("click", () => {
  alert("Merhaba");
});
HTML = yapı, JS = davranış. İkisini karıştırmamak, kodu okunaklı ve bakımı kolay tutar — büyük projelerde tercih her zaman harici dosyadır.
03 — Bağlama Yeri

<script> Nereye Konur?

  • <script> etiketi genelde </body>'nin hemen öncesine konur.
  • Neden? Tarayıcı sayfayı yukarıdan aşağı okur — script <head>'te olursa, henüz oluşmamış HTML elemanlarını seçmeye çalışıp hata verebilir.
  • Bu hatayı Hafta 15'te canlı olarak göreceğiz ("Butonum Neden Çalışmıyor?").
Kod
<body>
  ...tüm sayfa içeriği...

  <script src="script.js"></script>
</body>
04 — Yazılımcının En Yakın Dostu

Tarayıcı Konsolu (DevTools)

  • F12 (veya sağ tık → "İncele") ile tarayıcı geliştirici araçlarını, oradan Console sekmesini açıyoruz.
  • console.log(), kod içindeki bir değeri konsola yazdırmamızı sağlar — hata ayıklamanın (debugging) temelidir.
  • Bu dersten itibaren her uygulamada konsol açık olacak — kodun "ne düşündüğünü" orada göreceğiz.
Kod
console.log("Merhaba Konsol!");
console.log(5 + 3);  // 8
05 — Bilgiyi Saklama

Değişken (Variable) Nedir?

  • Değişken, bir değeri hafızada saklayıp sonra tekrar kullanmamızı sağlayan isimlendirilmiş bir kutudur.
  • Benzetme: Öğrenci karnesi üzerindeki her kutu (isim, not, sınıf) bir değişkendir — içine bir değer yazılır, sonra o kutuya isimle erişilir.
  • Javascript'te değişken tanımlamak için 3 anahtar kelime vardır: let, const, var (eski, artık kullanmıyoruz).
06 — Kod Karşılaştırma

var Neden Artık Kullanılmıyor?

var — ESKİ

Fonksiyon Kapsamlı, Sızıntı Yapar

for (var i = 0; i < 3; i++) {}
console.log(i);
// 3 — döngü bitmesine rağmen
// i'ye hâlâ erişilebiliyor!
let / const — YENİ

Blok Kapsamlı, Güvenli

for (let j = 0; j < 3; j++) {}
console.log(j);
// HATA! j döngü dışında
// tanımlı değil — beklenen davranış
Kural: Değeri hiç değişmeyecekse const, değişecekse let kullanın. var'ı bu derste hiç kullanmayacağız.
07 — Değerlerin Çeşitleri

Veri Tipleri (Data Types)

  • string — metin: "Merhaba"
  • number — sayı: 42, 3.14
  • boolean — doğru/yanlış: true, false
  • undefined — değer henüz atanmamış
  • null — değer bilerek boş bırakılmış
  • array, object — birden çok veriyi bir arada tutar (Hafta 17'de detaylı)
Kod
const ad = "Ahmet";      // string
const yas = 17;          // number
const ogrenciMi = true;  // boolean
08 — Tip Sorgulama

typeof Operatörü

  • Bir değişkenin hangi veri tipinde olduğunu öğrenmemizi sağlar.
  • Hata ayıklarken çok kullanışlıdır: "Bu değişken gerçekten sayı mı, yoksa string mi?"
Kod
console.log(typeof "Ahmet");  // "string"
console.log(typeof 17);       // "number"
console.log(typeof true);     // "boolean"
09 — Kod Karşılaştırma

Metin Birleştirme — Eski / Yeni

ESKİ — String Birleştirme

Artı işaretleriyle uzun ve karışık

const mesaj = "Merhaba, " + ad +
  "! " + yas + " yaşındasın.";
YENİ — Şablon Dizgesi

Ters tırnak + ${'{'} ${'}'} — okunaklı

const mesaj = `Merhaba, ${ad}! ${yas} yaşındasın.`;
Şablon dizgeleri (template literals) çift/tek tırnak yerine ters tırnak (backtick, `) kullanır, değişkenleri ${ } içine koyar.
10 — Bugünkü Bug Avının Zemini

Operatörler: Aritmetik ve Atama

  • Aritmetik: + - * / % (kalan)
  • Atama: = (ata), +=, -= (kısayol)
  • Kritik nokta: + operatörü, iki sayı arasında toplar, ama iki string arasında birleştirir (concat). Bu ikisini karıştırmak en sık yapılan başlangıç hatasıdır.
Kod
console.log(5 + 3);        // 8  (sayı + sayı)
console.log("5" + "3");    // "53" (string + string!)
11 — Canlı Kanıt — Bozuk Toplama

"Neden 5 + 8 = 58 Çıktı?"

Number() UNUTULMUŞ

input.value her zaman string'dir

const s1 = input1.value;  // "5" (string!)
const s2 = input2.value;  // "8" (string!)
const toplam = s1 + s2;
// toplam = "58" — birleşti, toplanmadı
Number() İLE ÇEVRİLDİ

Artık gerçekten sayı

const toplam = Number(s1) + Number(s2);
// toplam = 13 — doğru!
Birazdan örnek uygulamada bunu hata-nan.html ile canlı test edeceğiz — hatta virgüllü ondalık sayı (7,5) yazınca NaN (Not a Number) bile çıkabiliyor!
12 — Sayfayla Konuşmak

DOM Seçici: document.querySelector()

  • DOM (Document Object Model), tarayıcının HTML'i hafızada bir "ağaç yapısı" olarak temsil etme şeklidir.
  • document.querySelector("..."), CSS seçici sözdizimiyle (Hafta 9'da öğrendiğimiz #id, .class) sayfadan bir eleman seçmemizi sağlar.
  • Seçilen eleman, JS ile okunabilir/değiştirilebilir hâle gelir.
Kod
const baslik = document.querySelector("#okul-basligi");
console.log(baslik);
13 — Gerçek Proje

"Okulum" Projesine İlk JS Bağlantısı

  • index.html'in sonuna <script src="script.js"></script> ekliyoruz.
  • script.js içinde okulun bilgilerini değişkenlere atayıp konsola yazdırıyoruz.
const okulAdi = "Anadolu Teknik Lisesi";
const kurulusYili = 1998;
const ogrenciSayisi = 640;
const kayitAcik = true;

const bilgi = `${okulAdi}, ${kurulusYili} yılında kuruldu.`;
console.log(bilgi);
