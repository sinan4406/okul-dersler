Hakkımızda

Bölümlerimiz

  • Bilişim Teknolojileri — Web programlama, yazılım geliştirme, ağ yönetimi
  • Elektrik-Elektronik — Devre tasarımı, otomasyon sistemleri
  • Makine Teknolojisi — CNC, üretim planlama
