# Hafta 14 - Javascript'e Giriş, Değişkenler ve Veri Tipleri

**Öğrenme Birimi:** Etkileşim (Javascript)
**Ders Saati:** 8 (Haftalık)
**Durum:** Hazır (tam içerik)

## Bu Hafta İşlenecek Konular
- Javascript kod yazım kuralları
- Javascript eleman seçicileri (DOM seçiciler)
- Değişkenler ve veri tipleri
- Operatörlerin kullanımı ve kullanım yerleri

## Kazanımlar
- Değişkenler ve veri tiplerini kullanarak etkileşimli sayfalar geliştirir.

## Güncel Konu Notu (Öğretmen İçin)
let/const'un var yerine tercih edilmesi, şablon dizgeleri (template literals), tarayıcı geliştirici konsolu (DevTools) ile kod test etme alışkanlığı.
