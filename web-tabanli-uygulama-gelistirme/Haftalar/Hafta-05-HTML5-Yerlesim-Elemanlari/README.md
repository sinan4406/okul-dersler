# Hafta 05 - Yerleşim (Layout) Elemanları

**Öğrenme Birimi:** HTML5
**Ders Saati:** 8 (Haftalık)
**Durum:** Hazır (tam içerik)

## Bu Hafta İşlenecek Konular
- div ve span kavramları
- HTML5 semantik yerleşim etiketleri (header, nav, main, section, article, aside, footer)
- HTML5 tasarım şablonu oluşturma

## Kazanımlar
- Yerleşim (Layout) elemanlarını kullanarak örnek web uygulamaları geliştirir.

## Güncel Konu Notu (Öğretmen İçin)
Semantik HTML5 etiketlerinin (header/nav/main/section/article/aside/footer) div çorbası yerine tercih edilmesi; <template> ve <slot> ile yeniden kullanılabilir bileşen mantığına giriş (Web Components'e ön hazırlık).
