# Hafta 12 - Duyarlı (Responsive) Tasarım ve Media Query

**Öğrenme Birimi:** CSS (Basamaklı Stil Şablonu)
**Ders Saati:** 8 (Haftalık)
**Durum:** Hazır (tam içerik)

## Bu Hafta İşlenecek Konular
- Duyarlılık (Responsivity) kavramının önemi
- Farklı ortamlar için medya sorguları (media query) oluşturma

## Kazanımlar
- Duyarlılık (Responsivity) kavramının önemini açıklar.

## Güncel Konu Notu (Öğretmen İçin)
Container Query'ler (@container) ile bileşen tabanlı duyarlı tasarım, mobile-first medya sorgusu yazım stratejisi, clamp() ile akıcı (fluid) tipografi ve boşluklandırma.
