# Örnek Uygulama — Hafta 2: Site Değerlendirme Kontrol Listesi

## Amaç
Öğrencilerin bu haftaki 7 ilkeyi soyut bilgi olarak değil, **gerçek bir web sitesini inceleyerek** somut şekilde
kavraması.

## Ders İçi Uygulama (40-50 dk)

1. Sınıfı 3-4 kişilik gruplara ayırın.
2. Her gruba farklı bir web sitesi verin (öğretmen önceden seçer — biri iyi tasarlanmış, biri görece zayıf
   tasarlanmış olacak şekilde çeşitlendirin: örn. bir üniversite sitesi, bir haber sitesi, bir e-ticaret sitesi).
3. Her grup, aşağıdaki kontrol listesini kullanarak siteyi 1-5 arası puanlasın ve **neden** o puanı verdiğini
   yazsın.
4. Son 15 dakikada her grup bulgularını sınıfla paylaşsın.

## Kontrol Listesi (Öğrenciye Dağıtılacak)

| İlke | Kontrol Sorusu | Puan (1-5) | Not |
|---|---|---|---|
| İçerik | Site, ne hakkında olduğunu ilk 5 saniyede anlatıyor mu? | | |
| Tasarım | Header/ana içerik/footer düzeni net ve mantıklı mı? | | |
| Biçimsellik | Renkler ve fontlar tutarlı ve okunabilir mi? | | |
| İşlevsellik/Kullanılabilirlik | Menüde aradığınızı kolayca buluyor musunuz? | | |
| Güncellik | Site "eski" hissi veriyor mu, yoksa güncel mi görünüyor? | | |
| Uygunluk/Güvenilirlik | Yazım hatası var mı? İçerik özgün görünüyor mu? | | |
| Uyumluluk | Tarayıcı penceresini daraltınca site düzgün uyum sağlıyor mu? (responsive test) | | |

**Responsive test için pratik yöntem:** Tarayıcıda F12 (Geliştirici Araçları) → cihaz simülasyonu (mobil görünüm)
açılarak veya sadece tarayıcı penceresi elle daraltılarak sitenin nasıl tepki verdiği gösterilebilir.

## Sonraki Adım
Bu kontrol listesi, öğrencilerin Hafta 21'de başlayacağımız **Kütüphane Takip Sistemi** projesinin ana sayfa
tasarımını yaparken de kullanacakları bir referans olacak — bu bağı derste mutlaka vurgulayın.
