# Hafta 02 - Web Tasarım İlkeleri

**Öğrenme Birimi:** Web Tasarım İlkeleri
**Ders Saati:** 8 (Haftalık)
**Durum:** Hazır (tam içerik)

## Bu Hafta İşlenecek Konular
- İçerik
- Tasarım (yerleşim planı, site bileşenleri)
- Biçimsellik (renk düzeni, tipografi, okunabilirlik)
- İşlevsellik ve Kullanılabilirlik (kullanıcı dostu tasarım, site haritası)
- Güncellik (yeni teknolojiler)
- Uygunluk ve Güvenilirlik (alan adı, özgün içerik)
- Uyumluluk (tarayıcı uyumluluğu, responsive tasarım, media query)

## Kazanımlar
- Tasarım açısından içeriğin önemini açıklar.
- Tasarımda yerleşim planının uygunluğunu sağlar.
- Renk düzeni, okunabilirlik ve içerik-tasarım ilişkisini kurar.
- Web sitesinin kullanıcı dostu olmasını ve erişim kolaylığını sağlar.
- Yeni teknolojilerin kullanılmasının önemini açıklar.
- Web sitesinin alan adı, içerik vb. konularda uygunluğunu açıklar.
- Web sitesinin tüm platformlarda sorunsuz çalışması ilkesini (tarayıcı uyumluluğu, responsive tasarım, media query) açıklar.

## Güncel Konu Notu (Öğretmen İçin)
Erişilebilirlik standartları (WCAG 2.2), mobile-first tasarım yaklaşımı, Core Web Vitals ve sayfa performansının
SEO'ya etkisi, karanlık mod (dark mode) desteği, tasarım sistemleri (design system) ve Figma gibi işbirlikçi
tasarım araçları. Detaylar için [Güncel Konular ve Kaynaklar](../../00-Program-ve-Kaynaklar/Guncel-Konular-ve-Kaynaklar.md) dosyasına bakınız.

## Öğretmen İçin Ders Akış Önerisi (8 Ders Saati)
1. **(1 ders saati) Giriş:** "İyi tasarlanmış" ve "kötü tasarlanmış" iki web sitesi ekran görüntüsünü yan yana
   gösterip öğrencilere hangisini tercih edeceklerini ve neden sorun.
2. **(2 ders saati) İçerik ve Tasarım (yerleşim):** Sunumun 1-2. bölümleri.
3. **(2 ders saati) Biçimsellik (renk, tipografi) ve İşlevsellik/Kullanılabilirlik:** Sunumun 3-4. bölümleri.
4. **(1 ders saati) Güncellik ve Uygunluk/Güvenilirlik:** Sunumun 5-6. bölümleri.
5. **(1 ders saati) Uyumluluk (responsive, media query):** Sunumun 7. bölümü — telefonda/bilgisayarda aynı siteyi
   göstererek farkı gözlemletin.
6. **(1 ders saati) Uygulama:** 7 ilke kontrol listesiyle gerçek bir site değerlendirmesi (bkz. örnek uygulama).

## Bu Ünitenin Dönem Projesiyle İlişkisi

tasarımında da kullanılacak — bu yüzden öğrencilerin bu 7 ilkeyi iyi özümsemesi önemlidir.
