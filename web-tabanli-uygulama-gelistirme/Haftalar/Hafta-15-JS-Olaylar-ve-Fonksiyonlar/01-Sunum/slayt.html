01 — Tekrar Eden İşler

Fonksiyon (Function) Nedir?

  • Fonksiyon, belirli bir işi yapan, isimlendirilmiş, tekrar kullanılabilir bir kod bloğudur.
  • Benzetme: Bir yemek tarifi gibidir — malzemeleri (parametre) verirsiniz, tarif işlemi yapar, sonucu (return) size verir.
  • Aynı işlemi 5 yerde tekrar tekrar yazmak yerine, bir kere fonksiyon olarak yazıp 5 yerde çağırırız.
02 — Söz Dizimi

Fonksiyon Tanımlama

  • function anahtar kelimesi + fonksiyon adı + parantez içinde parametreler.
  • Fonksiyon çağrılmadan (ismiyle + parantezle kullanılmadan) hiçbir şey çalışmaz — sadece tanımlanmış olur.
Kod
function selamVer(isim) {
  console.log(`Merhaba, ${isim}!`);
}

// Çağırmadan hiçbir şey olmaz:
selamVer("Ahmet");  // "Merhaba, Ahmet!"
03 — Sık Karışan İkili

Parametre mi, Argüman mı?

Parametre

Fonksiyon tanımlanırken parantez içine yazılan, "yer tutucu" isimdir: function selamVer(isim) — isim bir parametredir.

Argüman

Fonksiyon çağrılırken gerçekten gönderilen değerdir: selamVer("Ahmet") — "Ahmet" bir argümandır.

04 — Sonucu Geri Vermek

return Anahtar Kelimesi

  • return, fonksiyonun bir sonuç değeri üretmesini sağlar — bu değer bir değişkene atanabilir.
  • return çalıştığı an fonksiyon durur, sonrasındaki satırlar çalışmaz.
  • return yoksa fonksiyon undefined döndürür.
Kod
function topla(a, b) {
  return a + b;
}

const sonuc = topla(5, 8);
console.log(sonuc);  // 13
05 — Kod Karşılaştırma

Ok (Arrow) Fonksiyonlar

KLASİK YAZIM

function anahtar kelimesiyle

function topla(a, b) {
  return a + b;
}
MODERN — ARROW

Daha kısa, yaygın kullanılıyor

const topla = (a, b) => {
  return a + b;
};
Ok fonksiyonlar, özellikle olay dinleyicisi (event listener) içinde kısa fonksiyonlar yazarken çok kullanılır — birazdan göreceğiz.
06 — Sayfayı Canlandırmak

Olay (Event) Nedir?

  • Olay, kullanıcının sayfada yaptığı bir eylemdir: tıklama (click), form gönderme (submit), fare üzerine gelme (mouseover), tuşa basma (keydown).
  • Tarayıcı bu olayları sürekli "dinler"; biz de "bu olay olduğunda şunu yap" diyerek JS ile tepki tanımlarız.
07 — Kod Karşılaştırma

Olay Dinleme — Eski / Yeni

SATIR İÇİ — kaçının

HTML ve JS karışık

<button onclick="alert('Merhaba')">
  Tıkla
</button>
addEventListener — modern

HTML ve JS ayrı, temiz

const btn = document.querySelector("button");
btn.addEventListener("click", () => {
  alert("Merhaba");
});
Bir elemana addEventListener ile birden fazla dinleyici eklenebilir — onclick ile sadece bir tane atanabilir, üzerine yazılırsa öncekini siler.
08 — Canlı Kanıt — Bozuk Buton

"Butonum Neden Çalışmıyor?"

SCRIPT head İÇİNDE

Buton henüz oluşmamış

<head>
  <script>
    const btn = document.querySelector("#btn");
    btn.addEventListener(...);
    // HATA: btn null!
  </script>
</head>
<body><button id="btn">...</button></body>
SCRIPT body SONUNDA

Buton zaten hazır

<body>
  <button id="btn">...</button>

  <script>
    const btn = document.querySelector("#btn");
    btn.addEventListener(...);
    // Çalışıyor!
  </script>
</body>
Birazdan örnek uygulamada bu hatayı buton-calismiyor.html ile canlı olarak konsolda göreceğiz: Cannot read properties of null.
09 — Olay Nesnesi

event.target ve e.preventDefault()

  • Olay dinleyicisi fonksiyonuna otomatik olarak bir olay nesnesi (genelde e veya event adıyla) gelir.
  • e.target, olayın gerçekleştiği HTML elemanını verir.
  • e.preventDefault(), tarayıcının o olay için yapacağı varsayılan davranışı durdurur — form gönderiminde sayfanın yeniden yüklenmesini engellemek için kritik.
Kod
form.addEventListener("submit", (e) => {
  e.preventDefault();  // sayfa yenilenmesin
  console.log("Form gönderildi!");
});
10 — Kısa Bir Not

Olay Kabarması (Event Bubbling)

  • Bir elemanda tetiklenen olay, o elemanı saran üst elemanlara doğru "kabarır" (yayılır).
  • Örnek: Bir butona tıklarsanız, önce butonun kendi click olayı, ardından onu saran <div>'in click olayı da (varsa) tetiklenir.
  • Şimdilik sadece farkında olmamız yeterli — ileri seviye JS derslerinde derinleşecek bir konu.
11 — Gerçek Proje

"Okulum" İletişim Formuna Olay Ekleme

  • Kendi yazdığımız geriBildirimGoster() fonksiyonu, form gönderildiğinde kullanıcıya mesaj gösterir.
  • submit olayına dinleyici ekliyoruz, e.preventDefault() ile sayfanın yenilenmesini engelliyoruz.
const iletisimFormu = document.querySelector("#iletisim-formu");

if (iletisimFormu) {
  iletisimFormu.addEventListener("submit", (e) => {
    e.preventDefault();
    geriBildirimGoster(kutu, "basarili", "Mesajınız alındı!");
  });
}
