# Hafta 13 - CSS Framework'leri ve Ünite Projesi

**Öğrenme Birimi:** CSS (Basamaklı Stil Şablonu)
**Ders Saati:** 8 (Haftalık)
**Durum:** Hazır (tam içerik)

## Bu Hafta İşlenecek Konular
- Popüler CSS framework'leri (Bootstrap, UI Kit, Materialize vd.)
- Ünite kapsamında mini proje / değerlendirme

## Kazanımlar
- Popüler frameworkleri listeler ve CSS frameworklerini açıklar.

## Güncel Konu Notu (Öğretmen İçin)
Bootstrap 5 grid sistemi ve utility class yaklaşımı, Tailwind CSS gibi utility-first framework'lerin yaygınlaşması, framework seçiminde proje ölçeğinin göz önünde bulundurulması.
