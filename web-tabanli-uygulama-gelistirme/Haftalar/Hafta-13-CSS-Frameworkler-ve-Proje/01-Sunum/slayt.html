Her seferinde sıfırdan yazmak yerine, hazır ve test edilmiş yapı taşlarını nasıl kullanırız?

01 — Yeni Kavram

CSS Framework Nedir?

  • Bir framework, önceden yazılmış, test edilmiş CSS (ve bazen JS) kodlarından oluşan hazır bir kütüphanedir.
  • Buton, kart, menü, grid (ızgara) sistemi gibi sık kullanılan bileşenleri sıfırdan yazmak yerine hazır class isimleriyle kullanmanızı sağlar.
  • Benzetme: Ev inşa ederken her tuğlayı kendiniz dökmek yerine, hazır prefabrik parçalar kullanmak gibidir — daha hızlı, ama esneklik biraz azalır.
02 — Neden Kullanılır?

Framework'ün Sağladığı Avantajlar

  • Hız: Bir navbar veya kart bileşenini dakikalar içinde kurabilirsiniz.
  • Tutarlılık: Tüm butonlar, boşluklar, renkler önceden tasarlanmış bir sisteme göre uyumludur.
  • Hazır duyarlılık: Grid sistemleri, Hafta 12'de öğrendiğimiz media query'leri sizin için otomatik uygular.
  • Tarayıcı uyumluluğu: Framework'ler, farklı tarayıcılardaki küçük tutarsızlıkları (cross-browser bugs) sizin yerinize çözmüştür.
03 — Ekosistem

Popüler CSS Framework'leri

Bootstrap — en yaygın, bileşen tabanlı Tailwind CSS — utility-first, güncel favori Bulma — Flexbox tabanlı, sade Materialize — Google Material Design UIKit — hafif, modüler
Bu derste Bootstrap 5'i temel alacağız çünkü öğrenmesi en kolay, dokümantasyonu en geniş ve sektörde hâlâ en yaygın kullanılan framework'tür.
04 — Kuruluma Gerek Yok

Bootstrap'i CDN ile Ekleme

  • CDN (Content Delivery Network), dosyayı kendi bilgisayarınıza indirmeden, internetteki bir sunucudan doğrudan kullanmanızı sağlar.
  • Tek yapmanız gereken, <head>'e bir <link> satırı eklemek.
  • İnternet bağlantısı gerektirir — büyük/kurumsal projelerde dosyalar genelde yerel olarak da indirilir.
Kod (head içine)
<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/
bootstrap@5.3.3/dist/css/bootstrap.min.css">
05 — Kod Karşılaştırma — 3 Sütunlu Düzen

Sıfırdan mı, Bootstrap Grid ile mi?

SIFIRDAN CSS

~10 satır, sizin sorumluluğunuzda

.satir { display: flex; gap: 16px; }
.sutun { flex: 1; }
@media (max-width: 700px) {
  .satir { flex-direction: column; }
}
BOOTSTRAP GRID

0 satır CSS, sadece class isimleri

<div class="row">
  <div class="col-md-4">...</div>
  <div class="col-md-4">...</div>
  <div class="col-md-4">...</div>
</div>
col-md-4, "orta (medium) ve üzeri ekranlarda 12 birimlik ızgaranın 4 birimini kapla" demektir — yani otomatik olarak 3 eşit sütun, mobilde ise otomatik olarak alt alta.
06 — Kod Karşılaştırma — Kart Bileşeni

Aynı Kart, İki Yöntem

SIFIRDAN CSS

~8 satır CSS yazmanız gerekir

.kart {
  border: 1px solid #ddd;
  border-radius: 8px;
  padding: 16px;
  box-shadow: 0 2px 6px #0002;
}
BOOTSTRAP

Hazır card sınıfı

<div class="card p-3">
  <h3>Başlık</h3>
  <p>İçerik...</p>
</div>
Birazdan örnek uygulamada aynı kartı her iki yöntemle de kendiniz yazıp süre/satır farkını gözlemleyeceğiz.
07 — Alternatif Yaklaşım

Utility-First: Tailwind CSS

  • Bootstrap "hazır bileşenler" (kart, navbar) sunarken, Tailwind küçük, tek işlevli class'lar (utility) sunar.
  • Kendi tasarımınızı bu küçük parçaları birleştirerek HTML içinde kurarsınız.
  • 2020'lerden itibaren özellikle React/Vue gibi bileşen tabanlı projelerde çok popülerleşti.
Kod (Tailwind örneği)
<div class="p-4 rounded-lg shadow bg-white">
  ...
</div>
08 — Madalyonun Diğer Yüzü

Framework'ün Bedelleri

AVANTAJ

Hız ve Tutarlılık

Projeye hızlı başlanır, ekip içinde ortak bir "dil" oluşur.

DEZAVANTAJ

Ağırlık ve Benzeşme

Kullanılmayan CSS kodu da indirilir (dosya boyutu artar); özelleştirilmemiş projeler "hepsi aynı görünüyor" eleştirisi alır.

Bu yüzden temel CSS'i (Hafta 9-12) iyi bilmeden framework kullanmak risklidir — framework'ün ürettiği kodu anlayıp gerektiğinde özelleştiremezsiniz.
09 — Karar Verme

Hangi Durumda Ne Kullanılır?

  • Küçük/kişisel proje, öğrenme amaçlı: Sıfırdan CSS — temelleri pekiştirmek için idealdir.
  • Hızlı prototip, kurumsal panel, MVP: Bootstrap gibi bileşen tabanlı framework — zamandan tasarruf sağlar.
  • Tamamen özgün, markaya özel tasarım: Tailwind gibi utility-first, veya framework'süz tam kontrol.
10 — CSS Ünitesi Kapanıyor

Ünite Projesi: "Okulum" Sitesinin Tamamlanması

  • Hafta 9-12'de "Okulum" projesine sırayla seçiciler, kutu modeli, renk/tipografi ve duyarlı tasarım ekledik.
  • Bu hafta, tüm bu stilleri gözden geçirip tek, temiz, tutarlı bir style.css dosyasında birleştiriyoruz — gerçek projelerde "refactoring" (kodu temizleme) adı verilen adım budur.
  • Ödevde ise öğrenciler kendi çok sayfalı sitelerini (Hafta 8'den itibaren) baştan sona CSS ile stillendirecek.
