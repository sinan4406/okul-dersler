# Hafta 01 - Web ve Yazılımcılık Temel Kavramları

**Öğrenme Birimi:** Temel Kavramlar
**Ders Saati:** 8 (Haftalık)
**Durum:** Hazır (tam içerik)

## Bu Hafta İşlenecek Konular
- Web sayfası / web sitesi kavramları
- Alan adı (domain), alan adı uzantıları, alan adı alma
- Hosting (barındırma) kavramı
- Web yazılımcısı rolleri: Front-end, Back-end, Full-stack
- HTML kodlarının yazılabileceği editörler
- CSS kavramına giriş
- WYSIWYG editör kavramı

## Kazanımlar
- Web sayfası yayınlama ile ilgili temel kavramları açıklar (web sayfası, web sitesi, alan adı, alan adı uzantıları, alan adı alma, hosting).
- Web yazılımcısı rollerini açıklar (front-end, back-end, full-stack).
- HTML kodlarının kullanılabileceği editörlere örnek verir; HTML ve CSS kavramlarını açıklar.
- WYSIWYG (What You See Is What You Get) editör kullanımını açıklar.

## Güncel Konu Notu (Öğretmen İçin)
Güncel hosting seçenekleri (Vercel, Netlify, GitHub Pages, bulut sağlayıcılar - Azure/AWS), Jamstack yaklaşımı,
no-code/low-code araçların yükselişi ve AI destekli kod editörlerinin (GitHub Copilot, Cursor vb.) front-end/back-end/
full-stack rollerini nasıl dönüştürdüğü. Detaylar için [Güncel Konular ve Kaynaklar](../../00-Program-ve-Kaynaklar/Guncel-Konular-ve-Kaynaklar.md) dosyasına bakınız.

## Bu Haftanın İçeriği
- [`01-Sunum/`](./01-Sunum/) — Ders sunumu ve anlatım notları
- [`02-Ornek-Uygulama/`](./02-Ornek-Uygulama/) — Derste birlikte yapılacak örnek uygulama
- [`03-Odev/`](./03-Odev/) — Öğrenci ödevi

## Öğretmen İçin Ders Akış Önerisi (8 Ders Saati)
1. **(1 ders saati) Giriş/motivasyon:** "Bir web sitesine girdiğinizde perde arkasında ne oluyor?" sorusuyla derse başlayın. Öğrencilerin günlük kullandığı 2-3 siteyi örnek gösterin.
2. **(2 ders saati) Web sayfası/site, alan adı, hosting:** Sunumun 1-3. bölümleri. Canlı olarak bir alan adı sorgulama sitesinde arama yaptırın (bkz. örnek uygulama).
3. **(2 ders saati) Front-end / Back-end / Full-stack rolleri:** Sunumun 4. bölümü. Örnek meslek profilleri, iş ilanı ekran görüntüleri üzerinden tartışma.
4. **(2 ders saati) Editörler, HTML/CSS kavramına giriş, WYSIWYG:** VS Code kurulumu/tanıtımı, ilk "Merhaba Dünya" sayfasının birlikte oluşturulması (bkz. örnek uygulama).
5. **(1 ders saati) Uygulama ve ödev tanıtımı:** Öğrencilerin kendi ortamlarında VS Code kurup ilk HTML dosyasını oluşturmaları, ödevin anlatılması.
