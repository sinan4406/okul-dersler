Web ve Yazılımcılık
Temel Kavramları

Web sayfası, alan adı, hosting ve yazılımcı rolleri ile derse başlıyoruz.

1

Web Sayfası mı, Web Sitesi mi?

  • ▸Web sayfası: Tarayıcıda gördüğünüz tek bir belge (tek bir HTML dosyası).
  • ▸Web sitesi: Bağlantılarla birbirine bağlı, aynı alan adı altındaki web sayfaları topluluğu.
  • ▸Benzetme: Bir kitabın her sayfası web sayfası, kitabın tamamı web sitesidir.
2

Alan Adı (Domain) Nedir?

Bir web sitesinin internet üzerindeki adresi (örn. meb.gov.tr). Bilgisayarlar aslında sayısal IP adresleri kullanır; alan adı sistemi (DNS) bu sayıları hatırlanabilir isimlere çevirir.

Alan adı = adres · Hosting = evin kendisi. Adresiniz olsa da eviniz yoksa kimse sizi ziyaret edemez.
3

Alan Adı Uzantıları

.com — ticari .org — kâr amacı gütmeyen .net — ağ hizmetleri .edu — eğitim .gov.tr — devlet (TR) .com.tr — ticari (TR)

.tr uzantıları nic.tr üzerinden, uluslararası uzantılar GoDaddy / Namecheap gibi firmalardan alınır. Fiyat, uzantıya göre değişir (.com ucuz, .ai gibi trend uzantılar pahalı).

4

Hosting (Barındırma)

Site dosyalarının 7/24 çalışan bir sunucuda saklanması ve internete açık tutulmasıdır.

Paylaşımlı Hosting Statik Site (GitHub Pages, Netlify, Vercel) Bulut Sunucu (Azure, AWS) Docker / Konteyner

Güncel: Bu dersin sonunda (Hafta 36) ASP.NET Core projemizi Azure App Service üzerinde yayınlayacağız.

5

Web Yazılımcısı Rolleri

RolNe yapar?Bu derste göreceğimiz araçlar
Front-endKullanıcının gördüğü ve etkileşime girdiği kısımHTML, CSS, Javascript

Benzetme: Front-end = restoranın salonu/menüsü, Back-end = mutfak, Full-stack = ikisini de yöneten kişi.

6

HTML Editörleri

  • ▸HTML kodu düz metindir; Not Defteri ile bile yazılabilir.
  • ▸Kod editörleri; sözdizimi renklendirme, otomatik tamamlama ve hata bulma sağlar.
  • ▸Bu derste kullanacağımız editör: Visual Studio Code (VS Code) — ücretsiz ve yaygın.
7

CSS'e Giriş

CSS (Basamaklı Stil Şablonları), HTML ile oluşturulan sayfanın görünümünü (renk, yazı tipi, boşluk, yerleşim) belirler.

Basit benzetme: HTML = iskelet/yapı, CSS = kıyafet/dış görünüm. Detayına Hafta 9'da gireceğiz.

8

WYSIWYG Editörler

"What You See Is What You Get" — kod yazmadan sürükle-bırak ile site tasarlama araçları (Wix, Webflow, WordPress sayfa oluşturucular).

Hızlıdır ama perde arkasını anlamayan biri sorun çıktığında düzeltemez. Bu derste amacımız perde arkasını (HTML/CSS/JS/.NET Core) gerçekten anlamak.
