# Hafta 09 - CSS'e Giriş, Ekleme Yöntemleri ve Seçiciler

**Öğrenme Birimi:** CSS (Basamaklı Stil Şablonu)
**Ders Saati:** 8 (Haftalık)
**Durum:** Hazır (tam içerik)

## Bu Hafta İşlenecek Konular
- CSS (Basamaklı Stil Şablonu) kavramı
- CSS ekleme yöntemleri (satır içi, dahili, harici)
- Stil uygulanacak elemanların seçimi (seçiciler)

## Kazanımlar
- Stil uygulanacak olan elemanların seçimini yapar.

## Güncel Konu Notu (Öğretmen İçin)
CSS ekleme yöntemlerinde harici (external) dosya kullanımının bakım/performans avantajı; modern seçiciler (:is(), :where(), :has()) ile daha az kod tekrarı.
