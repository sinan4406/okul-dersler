CSS — Bölüm 1

CSS'e Giriş, Ekleme
Yöntemleri ve Seçiciler

HTML'e "kıyafet" giydirmeyi öğreniyoruz — bir sayfayı nasıl renklendirir, biçimlendirir ve düzenleriz.

01 — CSS Nedir?

Basamaklı Stil Şablonları

  • CSS (Cascading Style Sheets), HTML ile oluşturulan sayfanın görünümünü belirleyen bir dildir.
  • Renk, yazı tipi, boşluk, boyut, yerleşim (layout) — hepsi CSS'in görevidir.
  • HTML "ne olduğunu" söyler (bu bir başlıktır), CSS "nasıl göründüğünü" söyler (bu başlık mavi ve büyük olsun).
02 — İş Bölümü

HTML mi, CSS mi?

HTML = Yapı

"Burada bir başlık var, burada bir liste var, burada bir buton var." İçeriği ve anlamı tanımlar.

CSS = Görünüm

"Bu başlık turuncu ve büyük olsun, bu liste yatay dizilsin." Görsel sunumu tanımlar.

Benzetme: HTML, bir insanın iskeleti ve organlarıdır. CSS ise o insanın kıyafeti, saç stili, makyajıdır — kimlik aynıdır ama görünüm tamamen değişebilir.
03 — Temel Söz Dizimi

Bir CSS Kuralı Nasıl Yazılır?

  • Seçici (selector): Hangi HTML elemanına uygulanacağını belirler.
  • Özellik (property): Neyi değiştireceğimizi belirler (renk mi, boşluk mu?).
  • Değer (value): Özelliğin ne olacağını belirler.
  • Her kural noktalı virgülle (;) biter, tüm blok süslü parantez içindedir.
Kod
p {
  color: blue;
  font-size: 18px;
}
04 — Ekleme Yöntemi 1

Satır İçi (Inline) CSS

  • Doğrudan HTML etiketinin içine, style="" özniteliği ile yazılır.
  • Sadece o tek etikete uygulanır.
  • Dezavantaj: Aynı stili başka bir yerde kullanmak istersek kodu kopyalamamız gerekir — bakımı zordur.
Kod
<p style="color: red; font-size: 20px;">
  Bu paragraf kırmızı!
</p>
05 — Ekleme Yöntemi 2

Dahili (Internal) CSS

  • <head> içine yerleştirilen bir <style> bloğu ile yazılır.
  • Aynı sayfadaki tüm eşleşen elemanlara uygulanır.
  • Dezavantaj: Sadece o sayfaya özeldir — başka bir sayfada aynı stili kullanmak için tekrar yazmak gerekir.
Kod
<head>
  <style>
    p { color: green; }
  </style>
</head>
06 — Ekleme Yöntemi 3

Harici (External) CSS

  • Stil kuralları ayrı bir .css dosyasında yazılır.
  • <link> etiketiyle istenen sayfaya bağlanır.
  • Avantaj: Aynı dosya, sitenin tüm sayfalarına bağlanabilir — tek yerden yönetim.
Kod
// index.html
<link rel="stylesheet" href="style.css">

// style.css
p { color: dodgerblue; }
07 — Hangisini Ne Zaman?

3 Yöntem Yan Yana

TEK SAYFA / TEK ELEMAN

Satır İçi

Hızlı test için kullanışlı ama büyük projede bakımı kâbustur — her yerde tekrar tekrar yazılır.

TEK SAYFA / ÇOK ELEMAN

Dahili

Tek sayfalık küçük projelerde ya da hızlı prototipte makul; çok sayfalı sitede tekrar gerektirir.

GERÇEK PROJE STANDARDI

Harici

Bir dosyayı değiştirin, siteye bağlı her sayfa aynı anda güncellensin. Bu ders boyunca ana yöntemimiz bu olacak.

08 — Seçiciler

Etiket (Type) Seçicisi

  • Bir HTML etiketinin adını doğrudan yazarız.
  • O etiketten sayfada kaç tane varsa hepsine uygulanır.
Kod
// Sayfadaki TÜM h2'ler turuncu olur
h2 { color: orange; }
09 — Seçiciler

Class Seçicisi — .sinif-adi

  • HTML'de class="..." ile etiketlenen elemanları seçer.
  • Başına nokta (.) konur.
  • Aynı class, birden fazla farklı etikete verilebilir — tekrar kullanılabilirlik sağlar.
Kod
<p class="uyari">...</p>

.uyari { color: red; }
10 — Seçiciler

ID Seçicisi — #id-adi

  • HTML'de id="..." ile etiketlenen tek bir elemanı seçer.
  • Başına diyez (#) konur.
  • Kural: Bir id değeri, bir sayfada sadece bir kez kullanılmalıdır (class ise defalarca kullanılabilir).
Kod
<p id="onemli-mesaj">...</p>

#onemli-mesaj { color: crimson; }
11 — Ne Zaman Hangisi?

Class mı, ID mi?

Class Kullan

Aynı stili birden fazla elemana uygulamak istiyorsanız (örn. tüm "uyarı kutuları", tüm "kartlar").

ID Kullan

Sayfada tek ve benzersiz bir elemanı işaretlemek istiyorsanız (örn. sayfanın ana başlığı, tek bir footer).

Genel kural: Pratikte çoğunlukla class kullanılır çünkü daha esnektir; ID daha çok Javascript ile bir elemanı bulmak için (Hafta 14+) tercih edilir.
12 — Çakışma Durumunda

Seçici Önceliği (Specificity)

  • Aynı elemana birden fazla kural farklı kaynaklardan uygulanabilir — hangisi kazanır?
  • Güçten zayıfa doğru sıralama: ID > Class > Etiket seçicisi.
  • Yani bir elemana hem class hem id ile stil verilmişse, ID kazanır.
Kod — Kim Kazanır?
p      { color: black;  } // en zayıf
.uyari { color: blue;   } // orta
#mesaj { color: red;    } // en güçlü — KAZANAN
Bunu birazdan örnek uygulamada secici-oncelik-demo.html ile canlı olarak test edeceğiz.
13 — Farkındalık Notu

Modern Seçiciler: :is(), :where(), :has()

  • :is() — birden çok seçiciyi tek satırda gruplar, tekrar yazmayı azaltır.
  • :has() — "içinde şu olan eleman" gibi ileri düzey eşleştirme sağlar (2023+ tüm modern tarayıcılarda desteklenir).
  • Bu dersin kapsamı dışında ayrıntılı işlenmeyecek, ama gerçek projelerde karşılaşabileceğiniz için farkındalık amaçlı gösteriyoruz.
// Eskisi: 3 satır
h1, h2, h3 { color: navy; }

// Modern: tek satır
:is(h1, h2, h3) { color: navy; }
