# Hafta 03 - HTML5'e Giriş ve Belge Yapısı

**Öğrenme Birimi:** HTML5
**Ders Saati:** 8 (Haftalık)
**Durum:** Hazır (tam içerik)

## Bu Hafta İşlenecek Konular
- HTML ve etiket (tag) kavramı
- HTML5 belge yapısı ve standart etiketler
- DOCTYPE kavramı
- Temel meta etiketleri
- HTML'de açıklama satırı
- HTML5'teki yeni özellikler
- İlk basit web sayfasının hazırlanması

## Kazanımlar
- HTML5 belge yapısını kullanarak basit bir web sayfası hazırlar.

## Güncel Konu Notu (Öğretmen İçin)
Modern meta etiketleri (viewport, charset=utf-8, Open Graph/SEO meta etiketleri), VS Code + Emmet ile hızlı HTML yazımı, erişilebilirlik için lang ve alt gibi temel özniteliklerin önemi.
