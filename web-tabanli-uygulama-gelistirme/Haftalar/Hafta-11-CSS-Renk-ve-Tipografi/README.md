# Hafta 11 - Renk Kullanımı ve Tipografi

**Öğrenme Birimi:** CSS (Basamaklı Stil Şablonu)
**Ders Saati:** 8 (Haftalık)
**Durum:** Hazır (tam içerik)

## Bu Hafta İşlenecek Konular
- RGB (Red, Green, Blue) değerleri ile renk tanımı
- Tipografi özellikleri ve kullanımı

## Kazanımlar
- RGB değerleri ile renk tanımı yapar.
- Tipografi özelliklerini açıklar ve kullanır.

## Güncel Konu Notu (Öğretmen İçin)
Modern CSS renk fonksiyonları (hsl(), oklch()), CSS özel değişkenleri (custom properties / --degisken) ile tema yönetimi, Google Fonts ve değişken (variable) fontlar, prefers-color-scheme ile karanlık mod.
