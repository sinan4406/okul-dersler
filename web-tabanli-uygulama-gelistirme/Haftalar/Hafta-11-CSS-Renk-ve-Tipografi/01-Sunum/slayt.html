Renk Kullanımı ve
Tipografi

Bir sitenin "kişiliğini" oluşturan iki şey: renk paleti ve yazı tipi seçimi.

01 — Neden Önemli?

Renk Sadece Süs Değildir

  • Renk, bir markanın kimliğidir — logonuzu görmeden bile rengiyle bir şirketi tanıyabilirsiniz (örn. kırmızı = bir kola markası).
  • Doğru renk kontrastı, içeriğin okunabilirliğini doğrudan etkiler.
  • Renkler duygu uyandırır: mavi güven, yeşil doğa/sağlık, kırmızı acil/dikkat çağrıştırır.
02 — Renk Tanımlama

HEX, RGB, İsimli Renkler

İsimli Renkler

color: red;

Hızlı ama sınırlı (~140 isim), hassas ton seçimi yapılamaz.

HEX Kod

color: #1a5fb4;

En yaygın kullanılan format — tasarım araçlarından (Figma vb.) doğrudan kopyalanabilir.

RGB Değeri

color: rgb(26, 95, 180);

Kırmızı/Yeşil/Mavi oranlarını 0-255 arası sayılarla ifade eder.

03 — RGB Nasıl Çalışır?

Kırmızı + Yeşil + Mavi

  • Ekranlar, ışığı 3 renk kanalıyla (Kırmızı, Yeşil, Mavi) karıştırarak milyonlarca renk üretir.
  • Her kanal 0 ile 255 arasında bir değer alır — 0 "hiç yok", 255 "tam doygun" demektir.
  • rgb(0, 0, 0) = siyah (hiç ışık yok), rgb(255, 255, 255) = beyaz (tüm kanallar tam).
04 — Farkındalık Notu

Modern Renk Fonksiyonları: hsl(), oklch()

  • hsl() — Renk Tonu (Hue), Doygunluk (Saturation), Açıklık (Lightness) ile tanımlar; "aynı tonun %20 daha koyusu" gibi ayarlamaları HEX'ten çok daha kolay yapar.
  • oklch() — 2023 sonrası tarayıcılarda desteklenen, insan gözünün algısına daha yakın, en modern renk formatıdır.
  • Bu ders kapsamında ayrıntılı işlenmeyecek, ama gerçek projelerde göreceğiniz için farkındalık amaçlı gösteriyoruz.
05 — Sık Yapılan Hata

Aynı Rengi Defalarca Yazmak

SÜRDÜRÜLEMEZ

Renk 5 Yerde Tekrarlanmış

.buton  { background: #ff6600; }
.baslik { background: #ff6600; }
.rozet  { background: #ff6600; }
// ...ve daha fazlası
SÜRDÜRÜLEBİLİR

Tek Bir Değişken

:root { --marka-rengi: #ff6600; }

.buton  { background: var(--marka-rengi); }
.baslik { background: var(--marka-rengi); }
Bunu birazdan örnek uygulamada renk-degiskeni-demo.html ile canlı olarak test edeceğiz — tek bir değeri değiştirip 5 elemanın birden değişmesini göreceğiz.
06 — CSS Özel Değişkenleri

:root { --degisken: ... }

  • :root, tüm sayfayı temsil eden özel bir seçicidir — buraya tanımlanan değişkenler her yerden erişilebilir.
  • Değişken isimleri her zaman iki tire ile başlar: --ornek-degisken.
  • Kullanmak için var(--degisken-adi) yazılır.
Kod
:root {
  --ana-renk: #1a5fb4;
  --ikincil-renk: #f2a154;
}

h1 { color: var(--ana-renk); }
07 — Erişilebilirlik

Yeterli Kontrast Şart

DÜŞÜK KONTRAST

Açık gri metin, beyaz zemin

Bu yazıyı okumak zorlaşır, özellikle görme zorluğu olan kullanıcılar veya parlak ışıkta ekrana bakanlar için neredeyse imkânsız hâle gelebilir.

YETERLİ KONTRAST

Koyu gri metin, beyaz zemin

Bu yazı net bir şekilde okunuyor — WCAG standardı normal metin için en az 4.5:1 kontrast oranı önerir.

08 — Tipografi Nedir?

Yazının Görsel Kimliği

  • Tipografi, metnin nasıl göründüğünü (yazı tipi, boyut, kalınlık, satır aralığı) düzenleme sanatıdır.
  • font-family — kullanılacak yazı tipi (fontu) belirler.
  • font-size — yazı boyutunu belirler.
  • font-weight — yazının kalınlığını belirler (normal, bold, 400, 700...).
09 — Font Kaynağı

Sistem Fontları mı, Google Fonts mu?

Sistem (Web-Safe) Fontlar

Arial, Georgia, Verdana gibi her bilgisayarda zaten yüklü fontlar. Ekstra yükleme gerektirmez, hızlıdır ama tasarımı sıradan bırakabilir.

Google Fonts

Yüzlerce ücretsiz, özgün font — internetten yüklenir. Siteye kişilik katar; bu derste "Okulum" projesinde kullanacağız.

10 — Uygulama

Google Fonts Nasıl Eklenir?

  • fonts.google.com'dan bir font seçilir.
  • Verilen <link> etiketi, sayfanın <head>'ine eklenir.
  • CSS'te font-family ile o fontun adı kullanılır.
Kod
// head içine
<link href="https://fonts.googleapis.com/..."
      rel="stylesheet">

// CSS'te
h1 { font-family: 'Poppins', sans-serif; }
11 — İnce Ayar

line-height ve letter-spacing

  • line-height — satırlar arası dikey boşluk. Çok sıkışık metin okumayı zorlaştırır (öneri: gövde metni için 1.5-1.7).
  • letter-spacing — harfler arası yatay boşluk. Büyük başlıklarda hafif negatif değer (örn. -0.01em) genelde daha modern görünür.
Kod
body { line-height: 1.65; }
h1    { letter-spacing: -0.01em; }
12 — Farkındalık Notu

Karanlık Mod: prefers-color-scheme

  • Kullanıcının işletim sistemi/tarayıcı tercihine göre (açık/karanlık mod) otomatik olarak farklı renkler uygulanabilir.
  • CSS özel değişkenleri kullanan bir site için bu, sadece birkaç satırla eklenebilir.
  • Bu ders kapsamında uygulamayacağız, ama "Okulum" gibi bir proje ileride bu şekilde geliştirilebilir.
@media (prefers-color-scheme: dark) {
  :root { --arkaplan: #111; --yazi-rengi: #eee; }
}
13 — Gerçek Proje

"Okulum" Renk Paleti ve Fontları

  • 5 renk değişkeni tek noktadan tanımlandı: --ana-renk, --ikincil-renk, --arkaplan, --yazi-rengi, --acik-gri.
  • Başlıklar için Poppins, gövde metni için Inter fontu Google Fonts'tan eklendi.
Kod — okulum/style.css
:root {
  --ana-renk: #1a5fb4;
  --ikincil-renk: #f2a154;
}
h1, h2, h3 { font-family: 'Poppins', sans-serif; }
body { font-family: 'Inter', sans-serif; }
