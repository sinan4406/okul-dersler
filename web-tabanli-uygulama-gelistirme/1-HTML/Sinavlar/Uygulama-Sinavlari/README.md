# Uygulama Sınavları (Bölüm 1.1 – 1.5)

```
Uygulama-Sinavlari/
├── sinav.css                         (talimat sayfalarının ortak stili)
├── Soru-1-Etkinlik-Duyurusu/
│   ├── talimat.html                  ← öğrenciye verilen sınav kâğıdı + puanlama listesi
│   ├── ogrenci-calisma/              ← öğrenci index.html'i buraya yazar
│   └── ornek-cozum/index.html        ← ders sorumlusu için
└── Soru-2-Cok-Sayfali-Site/
    ├── talimat.html
    ├── ogrenci-calisma/fotograf-atolyesi/   ← hazır klasör yapısı + boş katalog.pdf
    └── ornek-cozum/fotograf-atolyesi/       ← 4 HTML sayfası + katalog.pdf
```

- Öğrenciye yalnızca `talimat.html` ve `ogrenci-calisma/` verilir; `ornek-cozum/` verilmez.
- Soru 1: 45 dk · Soru 2: 60 dk · Her biri 100 puan.
