Web Eğitimlerimiz

HTML

HTML eğitimi, web tasarımı ve web geliştirme dünyasına adım atmak isteyenler için hazırlanmış temel bir eğitim programıdır. Bu eğitimde öğrenciler, web sayfalarının temel yapısını oluşturan HTML dilini başlangıç seviyesinden itibaren öğrenir. HTML belge yapısı, başlıklar, paragraflar, metin biçimlendirme etiketleri, bağlantılar, görseller, listeler, tablolar ve form elemanları gibi temel konular uygulamalı örneklerle ele alınır. Ayrıca ses ve video içeriklerinin web sayfalarına eklenmesi, sayfa içerisinde bağlantılar oluşturulması ve semantik HTML etiketleri kullanılarak daha anlamlı ve düzenli web sayfaları hazırlanması üzerinde durulur. Eğitim boyunca öğrenciler yalnızca HTML etiketlerinin nasıl kullanıldığını değil, bu etiketlerin gerçek web projelerinde hangi amaçlarla tercih edildiğini de öğrenir. Hazırlanan uygulamalar ve örnek projeler sayesinde öğrencilerin kendi web sayfalarını sıfırdan oluşturabilecek temel bilgi ve becerilere sahip olmaları amaçlanır.

Başa dön

CSS

CSS eğitimi, HTML ile oluşturulan web sayfalarının görsel olarak düzenlenmesini ve modern bir tasarıma dönüştürülmesini öğretir. Bu eğitimde öğrenciler; renkler, yazı tipleri, arka planlar, kenarlıklar, boşluklar, genişlik ve yükseklik gibi temel CSS özelliklerini kullanmayı öğrenir. Box Model yapısı ile HTML elemanlarının sayfa üzerindeki boyutlandırılması ve konumlandırılması ele alınırken, Flexbox ve CSS Grid gibi modern yerleşim yöntemleriyle farklı sayfa tasarımları oluşturulur. Ayrıca hover efektleri, geçişler, gölgeler ve çeşitli görsel düzenlemeler kullanılarak daha etkileyici kullanıcı arayüzleri hazırlanır. Eğitim kapsamında responsive tasarım tekniklerine de yer verilerek web sitelerinin bilgisayar, tablet ve telefon gibi farklı ekran boyutlarına uyum sağlaması öğretilir. Öğrenciler eğitim boyunca öğrendikleri CSS özelliklerini gerçek web sitesi örnekleri üzerinde uygulayarak menüler, kartlar, galeriler, formlar ve farklı sayfa düzenleri tasarlar. Eğitimin sonunda öğrencilerin HTML ile oluşturdukları web sayfalarını CSS kullanarak modern, düzenli, kullanıcı dostu ve farklı cihazlarla uyumlu web sitelerine dönüştürebilmeleri hedeflenir.

Başa dön

JavaScript

JavaScript eğitimi, HTML ve CSS ile oluşturulan web sayfalarına etkileşim ve dinamik özellikler kazandırmayı öğretir. Bu eğitimde öğrenciler; değişkenler, veri tipleri, operatörler, koşul ifadeleri, döngüler, fonksiyonlar, diziler ve nesneler gibi JavaScript programlama dilinin temel yapılarını öğrenir. Ardından DOM (Document Object Model) kullanılarak HTML elemanlarına JavaScript ile erişme, içerik ve stilleri değiştirme, yeni elemanlar oluşturma ve kullanıcı işlemlerine göre sayfayı güncelleme konuları ele alınır. Tıklama, klavye kullanımı ve form gönderme gibi olaylar (events) kullanılarak web sayfalarının kullanıcıyla etkileşim kurması sağlanır. Form doğrulama, açılır menüler, modal pencereler, görsel galerileri, sayaçlar ve dinamik içerikler gibi gerçek web sitelerinde sık kullanılan uygulamalar hazırlanır. Eğitimin ilerleyen bölümlerinde modern JavaScript özellikleri, JSON, yerel veri saklama ve API'lerden veri alma gibi konulara da yer verilir. Eğitim boyunca teorik bilgiler uygulamalarla desteklenerek öğrencilerin yalnızca JavaScript kodlarını öğrenmeleri değil, bu kodların gerçek web projelerinde nerede, neden ve nasıl kullanıldığını anlamaları hedeflenir. Eğitimin sonunda öğrencilerin HTML ve CSS ile hazırladıkları statik web sayfalarını JavaScript kullanarak etkileşimli, dinamik ve işlevsel web uygulamalarına dönüştürebilmeleri amaçlanır.
