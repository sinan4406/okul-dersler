# Okul Dersleri

Bilişim Teknolojileri alanı derslerine ait **ders planları, sunumlar, çalışma soruları**.
Sunumlar tek başına çalışan HTML dosyalarıdır; tarayıcıda açmanız yeterlidir (ok tuşları = ileri/geri, `F` = tam ekran).

## Dersler

| Ders | Sınıf | İçerik |
|---|---|---|
| [Bilişim Teknolojilerinin Temelleri](./bilisim-teknolojilerinin-temelleri) | 9 | Yapay zekâ sunumu, ders planı |
| [Nesne Tabanlı Programlama (C#)](./nesne-tabanli-programlama) | 10 | Haftalık sunumlar, çalışma soruları, genel tekrar/sınav |
| [Robotik ve Kodlama](./robotik-ve-kodlama) | 10 | Haftalık sunumlar, Arduino örnek kodları |
| [Web Tabanlı Uygulama Geliştirme](./web-tabanli-uygulama-gelistirme) | 11 | HTML5 sunuları, konu anlatımı, uygulamalar, sınavlar |

## Klasör Düzeni

```
<ders>/
  ders-plani/        → MEB ders planı (.docx)
  hafta-XX/ veya haftalik-dersler/ → sunum, sorular, örnek kodlar
```

> Not: Cevap anahtarları herkese açık olmaması için repoya eklenmemiştir.
> MEB ders kitabı PDF'leri telif ve boyut nedeniyle repoya dahil edilmemiştir.
